# English Quest — Telegram Mini App

Оригинальная обучающая Telegram Mini App по мотивам игрового обучения: **не копирует Duolingo**.

## Что реализовано в исходниках

- 12 тематических блоков A1–B2, около 100 исходных слов, 10 упражнений в уроке.
- 12 режимов: перевод, составление предложения, пары, аудирование, ввод перевода, пропущенное слово, быстрый перевод, змейка со стрелками, правда/ложь, диалоги, память, исправление ошибок.
- Стильная адаптивная React Mini App с тёмной и светлой темами, сохранением настроек, звуками через Web Audio, TTS английских слов через Web Speech API, виброоткликом Telegram (если поддерживается).
- Авторизация по проверенному `Telegram.WebApp.initData` (HMAC + возраст подписи), не по `initDataUnsafe`.
- Прогресс, XP, монеты, streak, рейтинг, словарь с простым алгоритмом интервального повторения, ограничение фарма XP, контроль прохождения уроков на сервере.
- Подписка Telegram Stars **с реальным инвойсом на 30 дней**, подтверждением платежа через `successful_payment`, автопродлением, учётом возврата и отключением продления.
- Профиль, простая административная статистика и настройка цены подписки.
- Рабочая локальная демо-авторизация без Telegram **только при `DEMO_MODE=true` и запросе с localhost**.

**Текущие ограничения:** это рабочая стартовая версия/исходники, не готовая к коммерческому релизу платформа. Не реализованы редактирование контента через админку, ежедневные сундуки и награды, пользовательские аватары/магазин, PvP, push-напоминания, полноценные переводы всех текстов интерфейса, аналитика и профилирование; озвучка зависит от поддержки TTS браузером; реальная оплата Stars требует вашего бота и проверки в Telegram. Разные уроки используют ограниченный набор авторских примеров. **Платежи не проверены в реальной транзакции**; до публичного запуска проведите тестирование и настройте политику конфиденциальности, поддержку платежей и мониторинг.

## 1. Запуск на своём компьютере

Нужны **Python 3.11+** и **Node.js 20+**. Две консоли:

**Сервер:**

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env       # Windows
# cp .env.example .env       # Linux/macOS
```

В файле `.env` для локального просмотра установи `DEMO_MODE=true`; `BOT_TOKEN` пока оставь пустым. Выполни:

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

**Интерфейс (второй терминал):**

```bash
cd frontend
npm install
npm run dev
```

Открой http://localhost:5173/ на этом ПК. Демо-пользователь включён **только локально**. Для полноценной проверки Mini App открывай через Telegram и используй HTTPS.

## 2. Подключение Telegram-бота

1. В Telegram открой **@BotFather**, создай бота командой `/newbot`, сохрани токен **секретно**.
2. На HTTPS-хостинге добавь `BOT_TOKEN=...`, `MINI_APP_URL=https://твой-публичный-домен/`, `DATABASE_URL=postgresql+psycopg2://...`, `DEMO_MODE=false`, `OWNER_TELEGRAM_ID=твой_цифровой_Telegram_ID`.
3. Собери фронтенд командой `cd frontend && npm install && npm run build`.
4. Запусти API из каталога `backend` командой `uvicorn main:app --host 0.0.0.0 --port 8000` (на PaaS — `$PORT`).
5. Открой бота и отправь `/start`: кнопка запускает Mini App на `MINI_APP_URL`. Можно также задать Menu Button в BotFather.

Не включай демо-режим на публичном сервере. **Один** процесс приложения на long polling (или переделай бота под webhook): два процесса с одним токеном приведут к конфликту polling.

## 3. Railway

1. Создай GitHub-репозиторий и помести в него содержимое этой папки.
2. Создай PostgreSQL в Railway и подключи его `DATABASE_URL` к сервису приложения.
3. Создай сервис из репозитория. `railway.json` содержит команды Nixpacks для установки зависимостей, сборки Vite и запуска API.
4. Добавь переменные из пункта 2 и публичный домен HTTPS Railway, нажми Deploy.
5. Отправь боту `/start`.

Если сборщик Railway не использует `railway.json`, настрой команды Build/Start по файлу вручную. Убедись, что Node.js, Python и postgresql-драйвер установлены.

## 4. Stars Premium

- `PREMIUM_STARS=149` — начальная цена. Владелец может изменить цену через «Админ-панель».
- Сервер создаёт `createInvoiceLink` с валютой `XTR`, `provider_token=''` и `subscription_period=2592000` секунд.
- После успешной покупки бот получает `successful_payment`, сохраняет charge ID и срок доступа; повторное событие не выдаёт второй доступ.
- Раздел Premium позволяет отменить **автопродление**, но не отнимает уже оплаченный доступ.
- Возвраты регистрируются при поступлении Telegram `refunded_payment`.
- Для практического возврата или поддержки добавь доступный контакт поддержки в политике бота и проверь работу `refundStarPayment`.
- Две игры «Змейка» и «Память» доступны Premium; **базовые уроки и остальные игры бесплатны**.

Текущую спецификацию платежей проверь перед запуском в https://core.telegram.org/bots/api ; Telegram может обновлять правила Stars.

## 5. Проверка

```bash
python -m pytest -q tests/
cd frontend
npm run build
```

На сервере открой `/api/health`. Проверка всех режимов и содержимого выполняется без телеграм-токена. Реальную авторизацию, Telegram WebView и оплату отдельно проверь в тестовом боте.

## Безопасность и продакшен

- Нельзя публиковать `.env` или Bot Token.
- Держи `DEMO_MODE=false` в продакшене.
- В случае обновлений БД используй проверенные миграции: текущий проект создаёт **начальную** схему через `Base.metadata.create_all()`, но **автоматических миграций существующей схемы нет**. Перед изменением моделей делай бэкап и миграции через Alembic.
- `score`/XP рассчитываются сервером по сохранённым вопросам, а не принимаются от клиента; это не отменяет необходимость антибот-защиты и нагрузочного тестирования при росте аудитории.
- Локально используется SQLite; в публичном проекте используй PostgreSQL с регулярными резервными копиями.
- Уведомления только включаются в настройках — автоматическая рассылка пока не подключена.
